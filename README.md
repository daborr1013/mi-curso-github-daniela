# Curso de Francés A2

Repositorio del curso **Français A2: Voyager, interagir et décider**.

El contenido del curso se encuentra en la carpeta [`docs`](docs/README.md), preparada para publicarse como sitio web educativo.

## Contenido

- Introducción y guía didáctica
- 4 unidades de aprendizaje
- Actividades interactivas
- Evaluación final
- Recursos en PDF/EPUB
- Autoevaluación según la norma UNE 71362
