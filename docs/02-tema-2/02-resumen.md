# Résumé – Unité 2. La vie quotidienne

## À retenir

- L’imparfait sert à décrire une habitude, un contexte ou une situation dans le passé.
- Le passé composé sert à raconter une action ponctuelle et terminée.
- On peut combiner les deux temps pour raconter une scène.

## Exemples

- *Je me levais à 8h.* → habitude
- *Il faisait froid.* → contexte
- *Je suis allé au travail.* → action ponctuelle
- *Je regardais la télévision quand tu as appelé.* → contexte + action

## Vocabulaire clé

- routine : se lever, se coucher, travailler, étudier, faire les courses
- moments : matin, après-midi, soir, nuit
- fréquence : toujours, souvent, parfois, rarement
