# Activité pratique - Unité 2

Pratiquez l'imparfait et le passé composé avec une activité interactive créée dans Ren'Py.

## Objectif

Choisir le temps verbal correct selon le contexte :

- l'imparfait pour les habitudes et les descriptions dans le passé ;
- le passé composé pour les actions ponctuelles ;
- le contraste entre une action en cours et une action qui l'interrompt.

## Activité Ren'Py
