# Activite Pratique - Unite 2

Pratiquez l'imparfait et le passe compose avec une activite interactive creee dans Ren'Py.

## Objectif

Choisir le temps verbal correct selon le contexte :

- l'imparfait pour les habitudes et les descriptions dans le passe ;
- le passe compose pour les actions ponctuelles ;
- le contraste entre une action en cours et une action qui l'interrompt.

## Activite Ren'Py

Le projet se trouve dans :

```text
docs/renpy/La-vie-quotidienne/
```

Ouvrez ce dossier avec Ren'Py et lancez le projet **La vie quotidienne**.

L'activite propose cinq situations courtes avec un score final sur 5.
