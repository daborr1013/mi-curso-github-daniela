📌 Unité 3 – Résumé

🗣️ Demander et se plaindre

👉 Demander poliment :

  • Je voudrais…
  • Pouvez-vous m’aider ?
  • Je voudrais parler à quelqu’un, s’il vous plaît.

👉 Se plaindre :

  • Il y a un problème
  • La chambre n’est pas propre
  • Pouvez-vous trouver une solution ?

📚 Pronoms COD / COI

COD → le, la, les COI → lui, leur Position → avant le verbe
  • Je prends le train → Je le prends
  • Je prends la chambre → Je la prends
  • Je parle à Marie → Je lui parle
  • Je parle au réceptionniste → Je lui parle
le / la / les → sans à
lui / leur → avec une personne introduite par à

🧩 Vocabulaire clé

problème, solution, aide, information

💬 Exemple

– Excusez-moi, je ne trouve pas ma réservation.
– Je vais vous aider.

– Excusez-moi, il y a un problème dans ma chambre.
– Qu’est-ce qu’il y a ?
– La chambre n’est pas propre. Pouvez-vous m’aider ?

✅ À retenir

  • Utiliser des formules polies
  • COD / COI remplacent le complément
  • Pronoms avant le verbe
  • Choisir le bon pronom selon le complément
