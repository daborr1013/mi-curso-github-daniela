## Rúbrica de evaluación

Puntuación: `0` no cumple, `0,5` cumple parcialmente, `1` cumple, `NA` no aplicable.

| Criterios / ítems | Puntuación | Observaciones |
|---|---:|---|
| **1. Descripción didáctica: valor y coherencia didácticos** |  |  |
| 1.1. Los objetivos didácticos se especifican de manera clara y precisa en el MED. |  |  |
| 1.2. Se especifican los destinatarios; los objetivos didácticos son alcanzables por los destinatarios según el perfil requerido en el propio MED. |  |  |
| 1.3. Las competencias y/o destrezas a desarrollar están claramente especificadas; son coherentes con los objetivos y los destinatarios. |  |  |
| 1.4. Existen instrucciones o sugerencias sobre los posibles usos didácticos para el profesor y/o para el estudiante. |  |  |
| 1.5. Se indica el tiempo estimado de aprendizaje. |  |  |
| 1.6. Se indican qué conocimientos previos del alumno son requeridos. |  |  |
| **Total criterio 1. Máximo 6 puntos** |  |  |
| **2. Calidad de los contenidos** |  |  |
| 2.1. El contenido es coherente con los objetivos didácticos. |  |  |
| 2.2. El contenido se presenta de manera clara y comprensible. Se destacan las ideas clave y se dan instrucciones claras en las actividades. |  |  |
| 2.3. Las ideas y conceptos se presentan en número adecuado y ordenada y equilibradamente a lo largo del MED. |  |  |
| 2.4. El contenido es científicamente correcto, no presenta sesgo ideológico, es objetivo y contiene información veraz. |  |  |
| 2.5. El contenido está actualizado o bien es intemporal. |  |  |
| 2.6. El contenido respeta los derechos de propiedad intelectual si utiliza otros materiales. |  |  |
| 2.7. El contenido declara las condiciones de uso del material educativo. |  |  |
| **Total criterio 2. Máximo 7 puntos** |  |  |
| **3. Capacidad para generar aprendizaje** |  |  |
| 3.1. El MED promueve el aprendizaje significativo del alumno. |  |  |
| 3.2. Se estimula la reflexión. |  |  |
| 3.3. Se estimula la capacidad crítica. |  |  |
| 3.4. Se fomenta la creatividad e innovación. |  |  |
| **Total criterio 3. Máximo 4 puntos** |  |  |
| **4. Adaptabilidad** |  |  |
| 4.1. El contenido se adapta al conocimiento previo del alumno y a sus necesidades de aprendizaje. |  |  |
| 4.2. Se puede modificar fácilmente el contenido o actividad del MED para ajustarlo a distintos grupos o tipos de alumnos. |  |  |
| 4.3. Se proponen diferentes contenidos, actividades o itinerarios según niveles, posibilidades y capacidades de aprendizaje. |  |  |
| 4.4. El MED respeta los distintos estilos de aprendizaje. |  |  |
| 4.5. Los contenidos pueden usarse independientemente del método de enseñanza y aprendizaje. |  |  |
| **Total criterio 4. Máximo 5 puntos** |  |  |
| **5. Interactividad** |  |  |
| 5.1. El MED fomenta la participación del alumno durante la lectura, visualización o interacción con el mismo. |  |  |
| 5.2. El MED contiene actividades interactivas para las ideas clave. |  |  |
| 5.3. Se facilita que el alumno controle y maneje su aprendizaje. |  |  |
| 5.4. Se puede obtener el historial de ejecución de la actividad del alumno. |  |  |
| 5.5. La tipología de actividades interactivas es variada. |  |  |
| **Total criterio 5. Máximo 5 puntos** |  |  |
| **6. Motivación** |  |  |
| 6.1. Existe relación entre lo aprendido y el entorno vital del destinatario del MED. |  |  |
| 6.2. Se promueve el aprendizaje autónomo del alumno. |  |  |
| 6.3. El tiempo de aprendizaje estimado es adecuado para alcanzar los objetivos didácticos. |  |  |
| 6.4. Los contenidos se presentan de forma atractiva o innovadora. |  |  |
| 6.5. Se favorece la comunicación y colaboración. |  |  |
| **Total criterio 6. Máximo 5 puntos** |  |  |
| **7. Formato y diseño** |  |  |
| 7.1. El diseño del MED está bien organizado y es claro, conciso e intuitivo. |  |  |
| 7.2. Las imágenes, audios y vídeos son de calidad. |  |  |
| 7.3. Los contenidos audiovisuales facilitan y/o refuerzan el aprendizaje. |  |  |
| 7.4. El MED incluye formato multimodal: texto, imagen, audio y/o vídeo. |  |  |
| 7.5. El manejo de la interfaz es intuitivo y, si no lo es, existen instrucciones de uso claras. |  |  |
| 7.6. La estética es compatible y adecuada al estudio del MED. No presenta ruido visual ni sobrecarga informativa innecesaria. |  |  |
| 7.7. Se mantiene la consistencia en la apariencia de los elementos que tienen la misma funcionalidad. |  |  |
| 7.8. Existe una opción de preferencias que permite personalizar la interfaz. |  |  |
| **Total criterio 7. Máximo 8 puntos** |  |  |
| **8. Reusabilidad** |  |  |
| 8.1. El MED se organiza modularmente de forma que es escalable. |  |  |
| 8.2. El MED o alguno de sus módulos puede utilizarse para crear nuevos MED. |  |  |
| 8.3. El MED o alguno de sus módulos puede utilizarse en más de una disciplina o grupo de alumnos. |  |  |
| **Total criterio 8. Máximo 3 puntos** |  |  |
| **9. Portabilidad** |  |  |
| 9.1. El MED se ha creado con formatos de uso mayoritario o estándares de facto. |  |  |
| 9.2. El alumno puede utilizar el MED con cualquier dispositivo con o sin conexión a internet. |  |  |
| 9.3. El MED tiene asociada una ficha de metadatos que lo describe. |  |  |
| 9.4. Los metadatos del MED están creados conforme a estándares internacionales. |  |  |
| 9.5. El MED se exporta utilizando estándares internacionales de intercambio de contenidos educativos. |  |  |
| **Total criterio 9. Máximo 5 puntos** |  |  |
| **10. Robustez; estabilidad técnica** |  |  |
| 10.1. El MED no falla durante su funcionamiento. |  |  |
| 10.2. El MED no se ve afectado por errores del usuario. |  |  |
| 10.3. El MED responde con rapidez, de forma visible y audible ante las acciones del usuario. |  |  |
| 10.4. Se proporcionan funciones de ayuda sobre problemas comunes y sus soluciones. |  |  |
| **Total criterio 10. Máximo 4 puntos** |  |  |
| **11. Estructura del escenario de aprendizaje** |  |  |
| 11.1. Cada escenario de aprendizaje tiene un título único y significativo. |  |  |
| 11.2. La estructura semántica y las relaciones de la información se explicitan en la presentación. |  |  |
| 11.3. Los escenarios permiten avanzar, mantener escenarios anteriores y volver a escenarios anteriores. |  |  |
| 11.4. Si se permiten escenarios superpuestos, se pueden minimizar, maximizar, cambiar tamaño, restaurar y cerrar. |  |  |
| **Total criterio 11. Máximo 4 puntos** |  |  |
| **12. Navegación** |  |  |
| 12.1. El nombre de cada enlace es descriptivo, claro y diferente del resto de los enlaces. |  |  |
| 12.2. Los enlaces funcionan correctamente. |  |  |
| 12.3. Se proporcionan, al menos, dos mecanismos para localizar cada escenario de aprendizaje de la interfaz. |  |  |
| 12.4. Se mantiene el orden lógico de navegación y la ubicación de los mecanismos de navegación. |  |  |
| 12.5. Se proporciona información al usuario acerca de dónde se encuentra dentro del MED. |  |  |
| 12.6. El alumno conoce su progreso en la ejecución del contenido. |  |  |
| 12.7. La interfaz proporciona tiempo ilimitado o suficiente para leer y usar el contenido. |  |  |
| 12.8. Se evita el paso obligado por elementos de contenido repetitivos. |  |  |
| 12.9. En cada inicio de sesión el contenido vuelve a su configuración inicial. |  |  |
| 12.10. El MED informa acerca de su estado activo o inactivo al usuario. |  |  |
| 12.11. Es posible salir del material en cualquier punto. |  |  |
| **Total criterio 12. Máximo 11 puntos** |  |  |
| **13. Operabilidad** |  |  |
| 13.1. El MED debe ser operable a través de acceso compatible o directo. |  |  |
| 13.2. La operatividad es completa con teclado, ratón y cualquier otro dispositivo de entrada. |  |  |
| 13.3. Se distingue visualmente dónde está el foco del teclado u otro dispositivo alternativo. |  |  |
| 13.4. No existe limitación temporal o existe un plazo que el alumno puede adaptar a su velocidad y necesidades. |  |  |
| 13.5. Se proporcionan atajos de teclado o teclas rápidas para enlaces principales y controles importantes. |  |  |
| 13.6. Todos los escenarios de aprendizaje aparecen y operan de manera predecible. |  |  |
| **Total criterio 13. Máximo 6 puntos** |  |  |
| **14. Accesibilidad del contenido audiovisual** |  |  |
| 14.1. Hay contraste suficiente entre el color de las imágenes y el color de fondo. |  |  |
| 14.2. Todos los contenidos audiovisuales tienen una descripción textual alternativa. |  |  |
| 14.3. Los contenidos audiovisuales tienen alternativas sincronizadas, como subtitulado, audiodescripción o transcripción. |  |  |
| 14.4. En los contenidos audiovisuales el alumno tiene el control de la reproducción y de sus alternativas textuales. |  |  |
| 14.5. Si el MED tiene sonidos inesperados, el alumno puede controlarlos. |  |  |
| 14.6. El contenido no incluye efectos de destello que puedan provocar ataques, espasmos o convulsiones. |  |  |
| 14.7. Si hay alertas visuales o sonoras, tienen sus respectivas alternativas. |  |  |
| **Total criterio 14. Máximo 7 puntos** |  |  |
| **15. Accesibilidad del contenido textual** |  |  |
| 15.1. El texto es legible y/o puede ajustarse su tamaño. |  |  |
| 15.2. Existe contraste entre el color de texto y el color del fondo. |  |  |
| 15.3. No se proporciona información exclusivamente por características sensoriales. |  |  |
| 15.4. Si hay formularios, tienen una estructura clara y coherente con la información que se presenta y solicita. |  |  |
| 15.5. Si hay tablas, se utilizan correctamente, están bien estructuradas y descritas. |  |  |
| 15.6. Si hay tablas, son sencillas y se utilizan para mostrar u organizar datos, no para maquetar contenido. |  |  |
| 15.7. Si hay listas, se utilizan para mostrar u organizar secuencias de elementos. |  |  |
| **Total criterio 15. Máximo 7 puntos** |  |  |
